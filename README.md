# BiblioTech

Systeme d Information de Gestion de Bibliotheque (SIGB)
Projet ecole - IPSSI Grande Ecole d Informatique - Promo 2025-2026
Auteur : Gregory Sergent

## Stack technique

- Frontend  : React 18 + TypeScript + Tailwind CSS v4 + Vite
- Backend   : Symfony 7 + API Platform + PHP 8.3 + Doctrine ORM
- Auth      : JWT RS256 - LexikJWTAuthenticationBundle
- DB        : PostgreSQL 16
- Desktop   : Tauri
- Infra     : Docker, Docker Compose

## Structure
